Generate shell completions for `px`.

Usage: px completions bash > ~/.local/share/bash-completion/completions/px px completions zsh > ~/.zfunc/_px px completions fish > ~/.config/fish/completions/px.fish source <(px completions bash)   # ephemeral

Usage: px completions [OPTIONS] <SHELL>

Arguments:
  <SHELL>
          Shell to generate completions for

          [possible values: bash, elvish, fish, powershell, zsh]

Options:
  -d, --base-dir <BASE_DIR>
          Base directory for repository repositories. Defaults to $PX_DIR, or ~/.px if unset

          [env: PX_DIR=]

  -v, --verbose
          Enable verbose debug logging

      --remote
          Resolve repository reads through the configured Lore server (the default)

      --local
          Resolve repository reads from an explicitly checked-out local working tree

  -h, --help
          Print help (see a summary with '-h')
