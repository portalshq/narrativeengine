Show a manifest diff for an entity URI

Usage: px diff [OPTIONS] <URI>

Arguments:
  <URI>  PX URI. The px:// prefix is optional

Options:
      --base-branch <BASE_BRANCH>
          Base branch
  -d, --base-dir <BASE_DIR>
          Base directory for repository repositories. Defaults to $PX_DIR, or ~/.px if unset [env: PX_DIR=]
      --candidate-branch <CANDIDATE_BRANCH>
          Candidate branch
  -v, --verbose
          Enable verbose debug logging
      --base-commit <BASE_COMMIT>
          Base commit
      --remote
          Resolve repository reads through the configured Lore server (the default)
      --candidate-commit <CANDIDATE_COMMIT>
          Candidate commit
      --local
          Resolve repository reads from an explicitly checked-out local working tree
  -f, --format <FORMAT>
          Output format: json, yaml [default: yaml]
  -h, --help
          Print help
