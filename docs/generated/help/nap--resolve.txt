Resolve a NAP URI to its manifest or a subtree.

Fragment queries are supported via the URI: nap resolve nap://toystory/character/woody#references.appears_in

Usage: nap resolve [OPTIONS] <URI>

Arguments:
  <URI>
          NAP URI. e.g., "nap://toystory/character/woody"

Options:
      --branch <BRANCH>
          Resolve at a specific branch

  -d, --base-dir <BASE_DIR>
          Base directory for repository repositories. Defaults to $NAP_DIR, or ~/.nap if unset
          
          [env: NAP_DIR=]

      --commit <COMMIT>
          Resolve at a specific commit hash

  -v, --verbose
          Enable verbose debug logging

  -f, --format <FORMAT>
          Output format: yaml, json
          
          [env: NAP_OUTPUT=]
          [default: yaml]

      --provenance
          Include condensed per-file provenance for the manifest and direct representations

      --include-blobs
          Hydrate known readable provenance artifacts such as prompts and run records

  -h, --help
          Print help (see a summary with '-h')
