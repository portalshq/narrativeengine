Validate a manifest against the NAP schema

Usage: nap validate [OPTIONS] [URI]

Arguments:
  [URI]  NAP URI of the entity to validate

Options:
  -d, --base-dir <BASE_DIR>  Base directory for repository repositories. Defaults to $NAP_DIR, or ~/.nap if unset [env: NAP_DIR=]
      --file <FILE>          Path to a manifest YAML file to validate
  -v, --verbose              Enable verbose debug logging
      --remote               Resolve repository reads through the configured Lore server (the default)
      --local                Resolve repository reads from an explicitly checked-out local working tree
  -h, --help                 Print help
