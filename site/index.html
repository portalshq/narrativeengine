05 / the developer surface

Install it.
Make something.

px ships with a CLI, agent skills, an on-demand MCP server, and a resolver for the narrative resources inside your project.

Install px + skills

curl -fsSL https://github.com/portalshq/narrativeengine/releases/latest/download/install.sh | bash && npx skills add portalshq/narrativeengine

Start a world

px init bears --provider local

# Create a character that the world can resolve
px create character lonnie -u bears -n "Lonnie"

Agents & MCP

Agents MUST issue all PX operations exclusively through the px-mcp-server MCP tools (px_<command>). The px CLI is NOT available for agentic use — never shell out, never follow px ... shell examples.

Representations

id: "px://toystory/scene/pizza-planet"
name: "Pizza Planet"

TypeScript SDK

import {repoCreateEntity} from '@portalshq/px'
